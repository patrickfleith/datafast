# Provider Examples

This folder contains direct, provider-focused examples.

- `openrouter/`: simple OpenRouter calls with `model.generate(...)`
- `anthropic/`: simple Anthropic calls with `model.generate(...)`
- `openai/`: simple OpenAI calls with `model.generate(...)`
- `gemini/`: simple Gemini calls with `model.generate(...)`
- `mistral/`: simple Mistral calls with `model.generate(...)`
- `ollama/`: simple local Ollama calls with `model.generate(...)`

These scripts are intentionally separate from `examples/scripts/`, which focuses on
pipeline usage.
